## 1. 基础知识

### 1.1 什么是 LSTM

LSTM（Long Short-Term Memory，长短期记忆网络）是一种特殊的循环神经网络(RNN)，通过"门控机制"解决了标准RNN的长期依赖问题。

**核心思想**：用"门"控制信息的流动，让网络自己学会"什么该记住、什么该忘记"。

```
标准RNN的困境:
  输入: "我出生在中国，...很长很长的句子...，我讲___"
  期望: "中文"            ← 需要记住"中国"
  RNN:  "英语"            ← "中国"信息在长距离传播中丢失了！

LSTM的解决方案:
  遗忘门: "中国"很重要，不要忘记！ → 保留信息
  输入门: 新信息"...很长..."不太重要 → 忽略噪声
  输出门: 需要回忆"出生地"来预测语言 → 输出相关信息
```

### 1.2 LSTM vs RNN vs FNN 的核心区别

| 对比项 | FNN (前馈网络) | RNN (循环网络) | LSTM (长短期记忆) |
|--------|---------------|---------------|------------------|
| **输入** | 固定大小向量 | 序列(可变长度) | 序列(可变长度) |
| **记忆** | 无(每次独立) | 短期(几步) | 长期(上百步) |
| **参数共享** | 无 | 时间步共享 | 时间步共享 |
| **梯度问题** | — | 梯度消失/爆炸 | 门控解决梯度问题 |
| **适用数据** | 表格/图像 | 短序列 | 长/短序列 |
| **训练难度** | 简单 | 困难(不稳定) | 中等(需要梯度裁剪) |

**为什么不用标准RNN？**
- 梯度消失：反向传播时梯度指数衰减，无法学习>10步的依赖
- 梯度爆炸：梯度指数增长，训练发散
- LSTM通过"细胞状态"(加法连接)让梯度可以直接流过，解决了这两个问题

### 1.3 LSTM 的关键组成

| 组件 | 作用 | 类比 |
|------|------|------|
| **遗忘门 (Forget Gate)** | 决定丢弃哪些旧信息 | 遗忘不重要的记忆 |
| **输入门 (Input Gate)** | 决定存入哪些新信息 | 记住重要的新信息 |
| **输出门 (Output Gate)** | 决定输出哪些信息 | 回忆相关的记忆 |
| **细胞状态 (Cell State)** | 信息高速公路 | 长期记忆的传送带 |
| **隐藏状态 (Hidden State)** | 当前输出 | 短期记忆/当前想法 |

### 1.4 训练流程

```
┌──────────────────────────────────────────────┐
│              每个 batch 重复执行               │
│                                              │
│  1. optimizer.zero_grad()  ← 清零梯度        │
│  2. outputs = model(x)     ← 前向传播        │
│  3. loss = criterion(…)    ← 计算损失        │
│  4. loss.backward()        ← 反向传播(求梯度) │
│  5. clip_grad_norm_(…)     ← 梯度裁剪(1.0)!  │
│  6. optimizer.step()       ← 更新参数        │
│                                              │
│  ⚠️ LSTM必须: 梯度裁剪(max_norm=1.0)          │
│  ⚠️ LSTM必须: 遗忘门偏置初始化为1.0            │
└──────────────────────────────────────────────┘
```

## 2. 技术原理

### 2.1 LSTM 内部结构

LSTM的核心是三个门和一条细胞状态：

```
                    ┌──────────────────────────────────┐
                    │           LSTM Cell               │
                    │                                  │
 c_{t-1} ──────→──×──→────────────────────────→──+──→ c_t
               遗忘门f    ↑                    输入门i·候选ĉ
               ↓         │                        ↑
 h_{t-1} ──→ [遗忘门]  [输入门]  [候选状态]  [输出门]
               ↑         ↑        ↑           ↑
               └─────────┴────────┴───────────┘
                         ↑
                   [h_{t-1}, x_t] 拼接

公式:
  遗忘门: f_t = σ(W_f·[h_{t-1}, x_t] + b_f)    → 0=丢弃, 1=保留
  输入门: i_t = σ(W_i·[h_{t-1}, x_t] + b_i)    → 0=不存, 1=存入
  候选态: ĉ_t = tanh(W_c·[h_{t-1}, x_t] + b_c) → 新候选值(-1到1)
  细胞态: c_t = f_t ⊙ c_{t-1} + i_t ⊙ ĉ_t     → 更新长期记忆
  输出门: o_t = σ(W_o·[h_{t-1}, x_t] + b_o)    → 0=不输出, 1=输出
  隐藏态: h_t = o_t ⊙ tanh(c_t)                → 当前输出
```

**为什么细胞状态能解决梯度消失？**

```
标准RNN:  h_t = tanh(W·h_{t-1} + U·x_t)
  梯度: ∂h_t/∂h_{t-1} = W·diag(1-h_t²)  → 每步乘以W，指数衰减！

LSTM:    c_t = f_t ⊙ c_{t-1} + i_t ⊙ ĉ_t
  梯度: ∂c_t/∂c_{t-1} = f_t              → 只乘以f_t(接近1时信息无损传递)
  
  关键: 这是加法(+)而非乘法(×)，梯度可以"无损"地沿细胞状态传回
  当遗忘门f_t≈1时，梯度几乎不衰减，可以学习上百步的依赖
```

### 2.2 遗忘门偏置初始化

```python
# LSTM偏置顺序: [input_gate, forget_gate, cell_gate, output_gate]
# 每个门有hidden_dim个偏置值

# 为什么遗忘门偏置初始化为1？
# σ(0) = 0.5  → 遗忘门=0.5，一半信息被丢弃(太激进了！)
# σ(1) = 0.73 → 遗忘门≈0.73，偏向于保留(更合理)
# 
# 初始时细胞状态为空，如果遗忘门=0，什么都记不住
# 设为1让模型"先记住，再学习该忘什么"

param.data[hidden_dim:2*hidden_dim].fill_(1.0)  # 遗忘门偏置=1
```

### 2.3 梯度裁剪

```
为什么LSTM必须裁剪梯度(max_norm=1.0)？

LSTM的反向传播路径:
  损失 → h_T → h_{T-1} → ... → h_1

每步梯度乘以:
  ∂h_t/∂h_{t-1} = W·(门控项)

如果W的特征值>1: 梯度指数增长 → 梯度爆炸
如果W的特征值<1: 梯度指数衰减 → 梯度消失

裁剪: 如果||梯度|| > max_norm, 缩放到max_norm
  效果: 限制梯度大小，防止参数更新太猛
  LSTM标准值: 1.0 (CNN用5.0，因为CNN的梯度通常更小)

torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

### 2.4 双向LSTM

```
单向LSTM:     只看"过去"的信息(从左到右)
  h_t = LSTM(x_t, h_{t-1})

双向LSTM:     同时看"过去"和"未来"(从左到右 + 从右到左)
  h_t→ = LSTM正向(x_t, h_{t-1}→)
  h_t← = LSTM反向(x_t, h_{t+1}←)
  h_t = [h_t→; h_t←]  (拼接两个方向的隐藏状态)

什么时候用双向？
  ✓ 文本分类: 理解整句话的语义，需要前后文
  ✓ 命名实体识别: 识别"苹果"是公司还是水果，需要上下文
  ✓ 机器翻译: 理解完整句子后翻译
  ✗ 文本生成: 不能看到未来(因果性约束)
  ✗ 实时预测: 不能等未来数据来了再预测
```

### 2.5 词嵌入 (Embedding)

```
为什么不用One-Hot而用Embedding？

One-Hot编码:
  "猫" → [0,0,0,1,0,0,...,0]  (10000维，1个1)
  "狗" → [0,0,0,0,1,0,...,0]  (10000维，1个1)
  问题: (1)维度灾难 (2)任意两个词距离相等(正交) (3)无法表达语义关系

Embedding编码:
  "猫" → [0.2, -0.5, 0.8, ...]  (64维稠密向量)
  "狗" → [0.25, -0.48, 0.75, ...]  (64维稠密向量)
  优势: (1)低维度 (2)语义相近的词向量距离近 (3)可学习

Embedding层本质: 一个查找表
  输入: 词索引(整数)
  输出: 对应的稠密向量
  参数: vocab_size × embedding_dim 的矩阵

nn.Embedding(vocab_size, embedding_dim, padding_idx=0)
  padding_idx=0: <PAD>的嵌入始终为0，不参与梯度更新
```

### 2.6 自编码器 (Autoencoder)

```
异常检测用的LSTM自编码器:

编码器: 输入序列 → LSTM → 瓶颈表示(低维)
  信息压缩: 将30维序列压缩到16维，只保留最关键的模式

瓶颈层: 全连接层，维度最小
  信息瓶颈: 迫使网络学习最本质的特征
  如果没有瓶颈: 模型可以"逐元素复制"，失去检测能力

解码器: 瓶颈表示 → LSTM → 重构序列
  信息重建: 从压缩表示重建原始序列

异常检测原理:
  正常数据: LSTM见过的模式 → 重构误差小
  异常数据: LSTM没见过的模式 → 重构误差大
  判定: 重构误差 > 阈值 → 异常！

阈值(3σ原则):
  阈值 = μ + 3σ (正常数据重构误差的均值 + 3倍标准差)
  覆盖99.7%的正常数据，超出即异常
```

## 3. 四大任务类型

### 3.1 时间序列预测 (Time Series Forecasting)

**目标**：给定过去seq_len个时间步的观测值，预测未来pred_len个时间步的值

```
输入: [x_{t-23}, x_{t-22}, ..., x_{t-1}, x_t]  ← 过去24步
                        ↓ LSTM
输出: [x_{t+1}, x_{t+2}, ..., x_{t+6}]          ← 未来6步预测
```

**模型**：LSTMForecaster — LSTM + 全连接层
**损失函数**：MSELoss（均方误差）
**评估指标**：MSE, RMSE, MAE, R²
**本模板数据**：合成正弦波数据(趋势+周期+噪声)

### 3.2 文本分类 (Text Classification)

**目标**：给定一段文本，判断它属于哪个类别

```
输入: "这部电影太精彩了" → 分词 → [这,部,电影,太,精彩,了]
      → Embedding → 双向LSTM → 最大池化 → FC → 类别概率
输出: 正面(0.92) / 负面(0.08) → 预测: 正面
```

**模型**：LSTMTextClassifier — Embedding + 双向LSTM + 最大池化 + FC
**损失函数**：CrossEntropyLoss
**评估指标**：Accuracy, Precision, Recall, F1
**本模板数据**：合成情感分析数据(200词, 3000条)

### 3.3 序列生成 (Sequence Generation)

**目标**：给定文本前缀，自回归生成后续内容

```
训练: Teacher Forcing — 每步输入真实答案
  输入: [今,天,天,气]  目标: [天,气,很,好]
  预测: [天,气,很?,好?]  → 计算损失(与真实对比)

推理: 自回归生成 — 每步输入上一步预测
  Step 1: [今] → 预测"天"
  Step 2: [天] → 预测"气"
  Step 3: [气] → 预测"很"
  ...
```

**模型**：LSTMGenerator — Embedding + LSTM + FC + 温度采样
**损失函数**：CrossEntropyLoss（逐词分类）
**评估指标**：Token准确率, 生成质量(人工评估)
**本模板数据**：合成模式序列(20词, 5000条)

### 3.4 时序异常检测 (Anomaly Detection)

**目标**：找出时间序列中"不正常"的数据点

```
训练: 只用正常数据训练LSTM自编码器
  正常序列 → 编码器 → 瓶颈 → 解码器 → 重构序列
  目标: 重构误差最小化(学习正常模式)

检测: 对新数据计算重构误差
  正常: 重构误差小(0.002) < 阈值(0.005) → 正常 ✓
  异常: 重构误差大(0.050) > 阈值(0.005) → 异常 ✗

三种异常类型:
  尖峰(Spike): 突发大幅值脉冲
  电平偏移(Level Shift): 信号整体偏移
  频率变化(Frequency Change): 信号频率异常
```

**模型**：LSTMAutoencoder — LSTM编码器 + 瓶颈层 + LSTM解码器
**损失函数**：MSELoss（重构误差）
**评估指标**：Precision, Recall, F1
**本模板数据**：合成传感器数据(正常3000条, 测试1000条含5%异常)

### 6.1 核心差异一览

| 对比项 | 时间序列预测 | 文本分类 | 序列生成 | 异常检测 |
|--------|------------|---------|---------|---------|
| **预测目标** | 未来数值 | 文本类别 | 下一个词 | 是否异常 |
| **输入类型** | 数值序列 | 词索引序列 | 词索引序列 | 数值序列 |
| **输出类型** | 连续值 | 类别概率 | 词概率分布 | 重构误差 |

### 6.4 数据处理差异

```
时间序列预测:
  数据: 连续数值序列
  预处理: 标准化(MinMax/Standard) → 滑动窗口切分
  划分: 按时间顺序(不能随机！)
  特殊: 只在训练集上fit标准化器

文本分类:
  数据: 文本 → 分词 → 词索引序列
  预处理: 截断/填充到统一长度 → Embedding
  划分: 可随机划分
  特殊: padding_idx=0(填充词不参与梯度更新)

序列生成:
  数据: 文本 → 分词 → 词索引序列
  预处理: 输入[0:T-1], 目标[1:T](错位1步)
  训练: Teacher Forcing(每步输入真实答案)
  推理: 自回归(每步输入上一步预测)

异常检测:
  数据: 连续数值序列
  预处理: 标准化 → 滑动窗口切分
  训练集: 只有正常数据(不用异常数据训练！)
  特殊: 阈值计算(3σ原则)
```

## 7. 常见问题与调优

### 7.1 梯度爆炸/NaN

**症状**：loss变为NaN或突然变得极大

**解决方案**：
```python
# 1. 梯度裁剪(LSTM必须！)
max_grad_norm = 1.0  # 不要超过5.0

# 2. 降低学习率
learning_rate = 1e-3  →  5e-4  →  1e-4

# 3. 检查数据是否有NaN/Inf
assert not np.isnan(data).any()

# 4. 使用更保守的权重初始化
nn.init.xavier_uniform_(param)  # 而非kaiming
```

### 7.2 过拟合（训练loss低，验证loss高）

**症状**：训练集表现好，验证/测试集表现差

**解决方案**：
```python
# 1. 增大Dropout
dropout = 0.2  →  0.3  →  0.5

# 2. 减小网络规模
hidden_dim = 128  →  64
num_layers = 3  →  2

# 3. 增大权重衰减
weight_decay = 1e-5  →  1e-4  →  1e-3

# 4. 数据增强(时序)
# - 添加轻微噪声
# - 时间扭曲(Time Warping)
# - 随机缩放

# 5. 使用更小的embedding_dim(文本任务)
embedding_dim = 128  →  64
```

### 7.3 欠拟合（训练和验证loss都高）

**症状**：训练集和验证集的表现都很差

**解决方案**：
```python
# 1. 加大网络规模
hidden_dim = 32  →  64  →  128
num_layers = 1  →  2  →  3

# 2. 增加训练轮数
epochs = 30  →  100  →  200

# 3. 增大学习率
learning_rate = 1e-4  →  1e-3

# 4. 增加输入序列长度
seq_len = 10  →  24  →  48

# 5. 使用双向LSTM(分类任务)
bidirectional = True
```

### 7.4 时间序列划分注意事项

```python
# ❌ 错误: 随机划分
from sklearn.model_selection import train_test_split
X_train, X_test = train_test_split(data)  # 未来信息泄露！

# ✅ 正确: 按时间顺序划分
train_data = data[:int(0.7 * len(data))]
val_data = data[int(0.7 * len(data)):int(0.85 * len(data))]
test_data = data[int(0.85 * len(data)):]

# 为什么？
# 随机划分: 用未来数据训练，预测过去 → 精度虚高
# 时序划分: 只用过去数据训练，预测未来 → 真实性能
```

### 7.5 LSTM层数选择指南

| 序列长度 | 数据量 | 推荐层数 | hidden_dim |
|---------|--------|---------|-----------|
| < 20 | < 1K | 1 | 32-64 |
| 20-100 | 1K-10K | 2 | 64-128 |
| 100-500 | 10K-100K | 2-3 | 128-256 |
| > 500 | > 100K | 2-3 | 256-512 |

> 经验：2层LSTM适合大多数场景，3层以上需要大量数据和精心调参

### 7.6 采样温度选择指南

| 温度 | 输出特点 | 适用场景 |
|------|---------|---------|
| 0.1-0.3 | 几乎确定，重复性高 | 代码生成(需要精确) |
| 0.5-0.8 | 略有变化，基本连贯 | 文本续写(创意写作) |
| 1.0 | 标准采样 | 通用 |

## 8. 进阶扩展

### 8.1 LSTM架构演进

```
RNN (1986)       → 循环连接，但无法学习长期依赖
LSTM (1997)      → 门控机制，解决长期依赖问题
GRU (2014)       → 简化LSTM(只有2个门)，参数少，训练快
Bi-LSTM (2005)   → 双向LSTM，同时考虑前后文
Stacked LSTM     → 多层堆叠，提取更抽象的时序特征
Attention-LSTM   → LSTM + 注意力机制，聚焦关键时间步
Transformer (2017)→ 自注意力替代循环，并行化，长距离依赖更强
```

### 8.2 GRU vs LSTM

```python
# GRU (Gated Recurrent Unit)
# 只有两个门: 更新门z_t + 重置门r_t
# 比LSTM少1/3参数，训练更快
# 性能通常与LSTM相当

class GRUCell:
    z_t = σ(W_z·[h_{t-1}, x_t])    # 更新门(合并了遗忘+输入)
    r_t = σ(W_r·[h_{t-1}, x_t])    # 重置门
    h̃_t = tanh(W·[r_t⊙h_{t-1}, x_t])
    h_t = (1-z_t)⊙h_{t-1} + z_t⊙h̃_t

# 何时选GRU？数据少、训练速度优先
# 何时选LSTM？数据多、精度优先、需要精细的门控
```

### 8.3 注意力机制 (Attention)

```python
# LSTM + Attention
# 让模型"关注"序列中最相关的时间步，而非只用最后一步

# 原理:
#   h_1, h_2, ..., h_T → 每个时间步的隐藏状态
#   注意力权重: α_i = softmax(score(h_i, query))
#   上下文向量: c = Σ α_i · h_i
#   最终表示: [c; h_T] → 分类/预测

# 好处:
#   1. 不再只依赖最后一步，利用所有时间步的信息
#   2. 可解释性：注意力权重显示模型"看"了哪里
#   3. 对长序列效果提升明显

# PyTorch实现
attention_weights = torch.softmax(
    torch.matmul(query, keys.transpose(-2, -1)) / sqrt(d_k),
    dim=-1
)
context = torch.matmul(attention_weights, values)
```

### 8.4 Transformer vs LSTM

| 对比项 | LSTM | Transformer |
|--------|------|-------------|
| **序列处理** | 顺序(逐个处理) | 并行(同时处理所有位置) |
| **长距离依赖** | 门控(有限) | 自注意力(任意距离) |
| **训练速度** | 慢(无法并行) | 快(高度并行) |
| **位置信息** | 天然有序 | 需要位置编码 |
| **参数量** | 较少 | 较多 |
| **小数据** | 更好(归纳偏置强) | 容易过拟合 |
| **大数据** | 次优 | 更好(可扩展) |
| **实时推理** | 适合(增量计算) | 不适合(需完整序列) |

### 8.5 实战技巧

```python
# 1. 隐藏状态是否跨batch传递？
#    分类/预测: 每个batch重新初始化(样本间无时序关系)
#    生成/在线预测: 可以跨batch传递(连续生成)

# 2. 多变量时间序列

#    方法3: 按长度分组batch(避免浪费)

# 4. 学习率调优
#    LSTM对学习率敏感:
#    - 1e-3: Adam标准值，大多数情况OK
#    - 如果训练不稳定 → 降到5e-4
#    - 如果收敛太慢 → 检查是否需要更多epoch而非更大LR
```
